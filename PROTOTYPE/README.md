# Mandate — functional prototype

This folder is a standalone interactive prototype of the planned Mandate gameplay loop.

Open `index.html` in a browser.

Implemented prototype flows:

- time controls and scheduled political events;
- player-controlled political party;
- party leader, program, organization, campaigning and funds;
- parliamentary elections and coalition building;
- presidential nomination, first round, **second round**, and inauguration;
- parliament, amendments, negotiations and law voting;
- local market prices and enterprise ownership changes;
- state identity reform, custom flag upload and currency reform;
- science grants and electricity research progress;
- interactive Map v2-style province mockup;
- persistent state through `localStorage`.

All numbers are demonstration values. The prototype is intentionally simplified and exists to demonstrate interaction and game flow, not final simulation formulas.
